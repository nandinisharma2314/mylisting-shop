# LOKOHUB — Full-Stack Local Business Platform

LOKOHUB is a full-stack local business discovery and listing platform that allows users to discover local businesses and provides an administrative dashboard for managing business listings and platform data.

The project is built with **Node.js, Express.js, EJS, MySQL, Cloudinary, and JavaScript**, with separate user-facing and admin applications.

### Frontend

* HTML5
* CSS3
* JavaScript
* EJS
* Bootstrap / responsive UI components

### Backend

* Node.js
* Express.js
* REST APIs
* Express Sessions
* Nodemailer

### Database

* MySQL

### Cloud Services

* Cloudinary for image storage and management
